## Rebuild

```bash
# put the Drive files next to the scripts (raw → proxy/photos/songs), then:
./fetch_one.sh D1 IMG_6494.MOV <drive-file-id> video/quicktime   # one per file; see the queue in the build log
python3 sheets.py photos && python3 sheets.py videos             # contact sheets for picking
python3 engine.py plan.py --only-base                            # cut + grade the shots
python3 engine.py plan.py --from-base                            # titles, transitions, audio, final.mp4
```

Needs `ffmpeg`, `numpy`, `pillow`, `pillow-heif`, `librosa`, `rembg` + `onnxruntime`,
and the Google Fonts listed in the skill.
